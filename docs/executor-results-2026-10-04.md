# Первый опыт: проверяемый нейронный исполнитель

Команда: `semop executor --device cpu`. Конфигурация: `configs/executor.toml`,
300 шагов, seed 42/43/44, dataset seed 20261004. PyTorch и версия Python
сохранены в `report.json`. Выбор checkpoint — только по validation;
во всех шести прогонах выбран шаг 300. После просмотра тестов обучение
не повторялось и гиперпараметры не менялись.

Обучение: 64 топологии, глубина 2–3, 6–9 узлов. Validation: 16 новых топологий.
Обычный тест: ещё 16 новых топологий. Длинный тест: 16 топологий,
глубина 6–8, 11–14 узлов. Топологии не пересекаются даже после удаления
имён, правил и значений источников. В каждой оценке — обе установки
одного целевого узла, 32 случая. Seed меняет обучение, а не тестовую выборку;
это не 96 независимых тестовых графов.

| Проверка | Трансформер, каждый из 3 seed | MLP, каждый из 3 seed |
|---|---:|---:|
| Параметры | 67 585 | 4 609 |
| Новые короткие графы: верны все узлы и шаги | 32/32 | 32/32 |
| Длинные графы: верны все узлы и шаги | 32/32 | 32/32 |
| Обе установки 0/1 на длинных графах | 16/16 пар | 16/16 пар |
| Изменившиеся свободные узлы, длинный тест | 110/110 | 110/110 |
| Повреждение неизменившихся свободных узлов, длинный тест | 0/158 | 0/158 |
| Два одновременных вмешательства, все узлы и шаги | 32/32 | 32/32 |
| Разовая подмена памяти, вся последующая траектория | 32/32 | 32/32 |
| Полная локальная таблица COPY/NOT | 8/8 | 8/8 |

Перед подменой памяти во всех 32 случаях каждой модели состояние было
правильным. Диагностика применяет импульс к реальному скалярному состоянию
и сравнивает дальнейшую траекторию с оракулом, получившим тот же импульс.
Состояние меняется один раз; постоянные исходные `do` продолжают действовать.
Самоподстановка не меняет траекторию. Максимальное изменение вероятностей
при перестановке номеров узлов — менее 3e-9.

В ходе ревью исправлен источник значения импульса для **ошибочных** состояний:
он всегда инвертирует текущий декодированный бит модели. Отдельный тест
воспроизводит прежнюю ошибку. Все шесть checkpoint загружены заново;
повторная диагностика после исправления совпала с исходной полностью.

Контроли, доля полностью правильных конечных состояний:

| Контроль | Новые короткие | Длинные | Два вмешательства |
|---|---:|---:|---:|
| Точный решатель | 32/32 | 32/32 | 32/32 |
| Только фиксация `do`, без распространения | 16/32 | 16/32 | 12/32 |
| Только один нейронный шаг | 25/32 | 18/32 | 32/32 |
| Каждый узел читает себя вместо родителя | 16/32 | 0/32 | 12/32 |

Все модели дали одинаковые декодированные результаты этих контролей.
Тест двух вмешательств оказался слабым: для его конкретных схем хватило
одного шага. Он проверяет одновременные ограничения, но не доказывает
обобщение многошаговой композиции. Более содержателен здесь длинный тест.

## Что означает результат

Модуль выучил локальные операции COPY/NOT и применил их рекуррентно
к новым графам большей глубины. Его динамическая память состоит из
одной вероятности на узел, поэтому её можно читать и причинно изменять
непосредственно. Полная восьмистрочная таблица проверяет выученный переход
на дискретных входах; она не доказывает поведение при всех возможных
непрерывных значениях вероятности.

MLP оказался достаточен и примерно в 15 раз меньше трансформера по числу
параметров. Преимуществ трансформера этот опыт не показал. Для подключения
языкового входа разумно сохранить обе реализации, а первым замороженным
исполнителем использовать MLP.

Граф, типы правил, исходное равновесие, привязка родителей и фиксация
источников/вмешательств предоставлены экспериментом. Модель не открыла
причинность, не извлекала знания из LFM и не училась универсальному
рассуждению. Проверен небольшой, наблюдаемый нейронный исполнитель известных
причинных механизмов. Следующий отдельный опыт — восстановление его
структурированного входа из текста при замороженном исполнителе.
